# The 24/7 AI Trader Blueprint

You can't watch the market all day. You have a job, a family, a life. So you check at lunch, see a move you missed, and chase it.

This blueprint builds the thing that watches for you. On a schedule, every hour or every night, it:

**SCAN → SIGNALS → PLAN → RISK → DECISION → LOG**

…and sends you one message per idea that ends in **APPROVE FOR REVIEW**, **WATCHLIST** or **REJECT**. It never places an order. You stay the trader; it does the homework.

You need: Python 3.10+, an [Anthropic API key](https://console.anthropic.com/) (pay as you go; a 6-ticker hourly scan usually costs cents a day because Claude only runs when a setup appears), and optionally a free Telegram bot (see step 6).

## The six modules (what each part of the code does)

**01 SCAN.** `scan()` pulls a year of daily bars from Yahoo Finance for each ticker on `WATCHLIST`, and `add_indicators()` adds the 20/50 EMAs, the prior 20-day high and low, ATR (how much it normally moves) and volume vs its 20-day average.

**02 SIGNALS.** `find_signal()` names one of two setups or returns nothing:
- **Breakout:** today closed above the prior 20-day high, on 1.2× normal volume.
- **Pullback:** in an uptrend (20 EMA above 50 EMA), price dipped to the 20 EMA and closed back above it.

**03 PLAN.** `build_plan()` writes entry, stop, target and the invalidation line. Breakouts use a 1.5× ATR stop and a 2R target; pullbacks use the 50 EMA (or the day's low) as the stop and the 60-day high as the target.

**04 RISK.** `risk_check()` is the bouncer. It sizes the position so a stop-out costs `RISK_PCT` of the account, caps any single name at `MAX_POSITION_PCT`, and **fails** the idea if reward:risk is below `MIN_REWARD_RISK`. A failed check forces REJECT, no matter how good the chart looks.

**05 DECISION.** `decision_memo()` sends only the numbers to Claude with strict rules: no invented news, no invented prices, under 110 words, and it must name the strongest reason *not* to take the trade. No API key yet? It falls back to the rule-based decision so you can test for free.

**06 MONITOR.** `notify()` texts you (or prints), and `log()` appends every idea to `trade_log.csv` so you can grade the system after 30 days.

## The rules that keep it honest

- **It never trades.** There is no broker connection in this code, on purpose. You look at the chart and decide.
- **The risk check outranks the AI.** A failed check is REJECT, and the prompt enforces it.
- **Grade it before you trust it.** After 30 days, open `trade_log.csv` and check what happened after each APPROVE, WATCHLIST and REJECT. Change one rule at a time.

> **Before you rely on this:** Educational only, not financial advice. Signals fire on daily data and can be late or wrong; data feeds can glitch; AI can misread. Start with tiny size or none at all, and you make every decision.

## The full script

```python
"""The 24/7 AI Trader Blueprint: scan -> signals -> plan -> risk -> Claude memo -> phone -> log.
Runs once per call. Schedule it (cron, GitHub Actions, Replit Scheduled Deployment) to keep it on 24/7.
Educational code. Not financial advice. It NEVER places orders: every idea needs your approval.

pip install anthropic yfinance pandas requests
Env vars: ANTHROPIC_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID (optional)
"""
import csv
import datetime as dt
import json
import os

import anthropic
import pandas as pd
import requests

WATCHLIST = ["SPY", "QQQ", "AAPL", "MSFT", "NVDA", "AMZN"]
ACCOUNT = 10_000          # account size in dollars
RISK_PCT = 1.0            # % of account risked per idea
MAX_POSITION_PCT = 25.0   # never more than this % of the account in one name
MIN_REWARD_RISK = 2.0     # skip anything paying less than 2x the risk
LOG_FILE = "trade_log.csv"


# 01 SCAN: pull daily bars and compute the basics
def scan(ticker: str) -> pd.DataFrame:
    import yfinance as yf
    df = yf.download(ticker, period="1y", interval="1d", auto_adjust=True, progress=False)
    df.columns = [c[0] if isinstance(c, tuple) else c for c in df.columns]
    return add_indicators(df)


def add_indicators(df: pd.DataFrame) -> pd.DataFrame:
    df = df.copy()
    df["ema20"] = df.Close.ewm(span=20, adjust=False).mean()
    df["ema50"] = df.Close.ewm(span=50, adjust=False).mean()
    df["high20"] = df.High.rolling(20).max().shift(1)
    df["low20"] = df.Low.rolling(20).min().shift(1)
    tr = pd.concat([df.High - df.Low, (df.High - df.Close.shift()).abs(), (df.Low - df.Close.shift()).abs()], axis=1).max(axis=1)
    df["atr"] = tr.rolling(14).mean()
    df["vol_ratio"] = df.Volume / df.Volume.rolling(20).mean()
    return df.dropna()


# 02 SIGNALS: name the setup, or return None
def find_signal(df: pd.DataFrame) -> str | None:
    last, prev = df.iloc[-1], df.iloc[-2]
    uptrend = last.ema20 > last.ema50
    if last.Close > last.high20 and prev.Close <= prev.high20 and last.vol_ratio > 1.2:
        return "breakout"
    if uptrend and last.Low <= last.ema20 < last.Close:
        return "pullback"
    return None


# 03 PLAN: entry, stop, target, invalidation
def build_plan(df: pd.DataFrame, setup: str) -> dict:
    last = df.iloc[-1]
    entry = float(last.Close)
    stop = float(entry - 1.5 * last.atr) if setup == "breakout" else float(min(last.Low, last.ema50))
    risk = entry - stop
    target = float(entry + MIN_REWARD_RISK * risk) if setup == "breakout" else float(df.High.tail(60).max())
    return {"setup": setup, "entry": round(entry, 2), "stop": round(stop, 2), "target": round(target, 2),
            "reward_risk": round((target - entry) / risk, 2) if risk > 0 else 0.0,
            "invalidation": f"daily close below {round(stop, 2)}"}


# 04 RISK: size it, cap it, or block it
def risk_check(plan: dict) -> dict:
    per_share = plan["entry"] - plan["stop"]
    checks = {"stop_below_entry": per_share > 0, "reward_risk_ok": plan["reward_risk"] >= MIN_REWARD_RISK}
    shares = int(ACCOUNT * RISK_PCT / 100 // per_share) if per_share > 0 else 0
    max_shares = int(ACCOUNT * MAX_POSITION_PCT / 100 // plan["entry"])
    checks["size_capped"] = shares <= max_shares
    shares = min(shares, max_shares)
    checks["has_size"] = shares > 0
    return {"shares": shares, "max_loss": round(shares * per_share, 2), "checks": checks,
            "passed": all(v for k, v in checks.items() if k != "size_capped")}


# 05 DECIDE: Claude writes the memo; a human approves
client = anthropic.Anthropic() if os.environ.get("ANTHROPIC_API_KEY") else None
MEMO_RULES = """You are the decision desk of an educational trading research system. You never place trades.
Use ONLY the data given. Never invent prices, news or indicators. Under 110 words, exactly this format:
SUMMARY: one line
SIGNAL STRENGTH: 1-5 and why
RISK: what the risk check found
PLAN: entry / stop / target / reward:risk / shares
STRONGEST REASON NOT TO: one line
DECISION: APPROVE FOR REVIEW / WATCHLIST / REJECT
If the risk check failed, DECISION must be REJECT."""


def decision_memo(ticker: str, plan: dict, risk: dict, df: pd.DataFrame) -> str:
    if client is None:
        return "DECISION: " + ("APPROVE FOR REVIEW" if risk["passed"] else "REJECT") + " (no API key: rules only)"
    last = df.iloc[-1]
    data = {"ticker": ticker, "date": str(df.index[-1].date()), "close": round(float(last.Close), 2),
            "ema20": round(float(last.ema20), 2), "ema50": round(float(last.ema50), 2),
            "atr": round(float(last.atr), 2), "volume_ratio": round(float(last.vol_ratio), 2),
            "plan": plan, "risk_check": risk}
    response = client.messages.create(
        model="claude-opus-5-5", max_tokens=2000, output_config={"effort": "medium"},
        system=MEMO_RULES, messages=[{"role": "user", "content": json.dumps(data)}])
    if response.stop_reason == "refusal":
        return "DECISION: REJECT (Claude declined to write a memo)"
    return "".join(b.text for b in response.content if b.type == "text")


# 06 MONITOR: send it to your phone and log it for review
def notify(text: str) -> None:
    token, chat = os.environ.get("TELEGRAM_BOT_TOKEN"), os.environ.get("TELEGRAM_CHAT_ID")
    if token and chat:
        requests.post(f"https://api.telegram.org/bot{token}/sendMessage", json={"chat_id": chat, "text": text}, timeout=15)
    else:
        print(text)


def log(row: dict) -> None:
    new = not os.path.exists(LOG_FILE)
    with open(LOG_FILE, "a", newline="") as f:
        w = csv.DictWriter(f, fieldnames=list(row))
        if new:
            w.writeheader()
        w.writerow(row)


def run(fetch=scan) -> None:
    for ticker in WATCHLIST:
        df = fetch(ticker)
        setup = find_signal(df)
        if not setup:
            continue
        plan = build_plan(df, setup)
        risk = risk_check(plan)
        memo = decision_memo(ticker, plan, risk, df)
        notify(f"🤖 {ticker} · {setup.upper()}\n\n{memo}\n\nHuman approval required. Nothing has been traded.")
        log({"time": dt.datetime.now().isoformat(timespec="minutes"), "ticker": ticker, **plan,
             "shares": risk["shares"], "risk_passed": risk["passed"], "memo": memo.replace("\n", " | ")})


if __name__ == "__main__":
    run()
```
