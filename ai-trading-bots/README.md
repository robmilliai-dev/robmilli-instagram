# AI Trading Bots: free starter kits, tested

I test viral AI trading bots so you don't have to. Most fail. The few that pass, I rebuild and give away here as free starter kits.

Each folder has: how the bot works in plain English, a copy-paste prompt that builds a starter version with Claude Code in about 20 minutes (or the full Pine code for the TradingView indicators), and a troubleshooting table. Free, open source (MIT).

> **Safety first:** every starter runs in demo or read-only mode. No broker or wallet code, no private keys, never places a trade. Keep API keys in `.env`, never in GitHub.

## How to use this repo

1. Pick a bot from the table.
2. Open its folder and read **How it works** (2 minutes).
3. Copy the build prompt into [Claude Code](https://code.claude.com/docs/en/quickstart) and run the demo.
4. Want the step-by-step guide with 12 more prompts? Grab it free at the link in the table.
