# earnings-game-plan: a Claude Code skill from Milli.ai

The Earnings Game Plan skill. Decide before the number drops: landmines table, the move options expect vs. the last four, three if/then scenarios, size math, minute-by-minute plan and a one-page cheat sheet.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment EARNINGS on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/earnings-game-plan/` (every project) or `.claude/skills/earnings-game-plan/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/earnings-game-plan` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "Earnings Game Plan".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Nothing beyond Claude Code (or paste SKILL.md into a Claude Project / ChatGPT custom GPT).

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
