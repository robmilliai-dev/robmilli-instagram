# reel-script: a Claude Code skill from Milli.ai

The Reel Script skill. Three hooks from different families ranked, a 45-second script with on-screen text and B-roll cues, caption, keyword CTA and a prediction against your own past reels.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment SCRIPT on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/reel-script/` (every project) or `.claude/skills/reel-script/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/reel-script` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "Reel Script".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Nothing beyond Claude Code (or paste SKILL.md into a Claude Project / ChatGPT custom GPT).

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
