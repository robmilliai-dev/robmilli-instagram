# skill-builder: a Claude Code skill from Milli.ai

The Skill Builder. Turn anything you repeat as a trader into a reusable skill: intake, process, rules with reasons, output contract, self-check, stop-and-show. Tested on your real example.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment SKILLBUILD on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/skill-builder/` (every project) or `.claude/skills/skill-builder/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/skill-builder` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "Skill Builder".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Nothing beyond Claude Code (or paste SKILL.md into a Claude Project / ChatGPT custom GPT).

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
