# ticker-deep-dive: a Claude Code skill from Milli.ai

The Ticker Deep Dive skill. Eight research passes into one 8-section brief: what they sell, the numbers, earnings pattern, insiders, chart, 90 days of news, catalysts, the bear case. Every fact sourced.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment RESEARCH on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/ticker-deep-dive/` (every project) or `.claude/skills/ticker-deep-dive/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/ticker-deep-dive` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "Ticker Deep Dive".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Nothing beyond Claude Code (or paste SKILL.md into a Claude Project / ChatGPT custom GPT).

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
