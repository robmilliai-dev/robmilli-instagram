# pine-script-writer: a Claude Code skill from Milli.ai

The Pine Script Writer. Plain English to TradingView Pine Script v6, then checked for repainting, lookahead, unconfirmed-bar signals and missing costs. Webhook-ready alerts included.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment PINE on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/pine-script-writer/` (every project) or `.claude/skills/pine-script-writer/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/pine-script-writer` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "Pine Script Writer".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Nothing beyond Claude Code (or paste SKILL.md into a Claude Project / ChatGPT custom GPT).

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
