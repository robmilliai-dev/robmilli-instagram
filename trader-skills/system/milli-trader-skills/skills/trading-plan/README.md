# trading-plan: a Claude Code skill from Milli.ai

The Trading Plan skill. Your written trading plan: your honest rung on the Bot Ladder, one market that fits your time and money, risk rules first, a 90-day path from manual to automated, the don't-do list and a weekly scoreboard. HTML + PDF.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment PLAN on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/trading-plan/` (every project) or `.claude/skills/trading-plan/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/trading-plan` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "Trading Plan".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Nothing beyond Claude Code (or paste SKILL.md into a Claude Project / ChatGPT custom GPT).

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
