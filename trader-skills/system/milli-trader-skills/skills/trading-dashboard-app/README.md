# trading-dashboard-app: a Claude Code skill from Milli.ai

Build Your Trading Dashboard App. Your own private dashboard on a link: watchlist, alert log via webhook, bot status with a KILL switch, weekly scoreboard. The exact starter prompt and the build order that avoids dead ends.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment APP on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/trading-dashboard-app/` (every project) or `.claude/skills/trading-dashboard-app/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/trading-dashboard-app` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "Build Your Trading Dashboard App".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Nothing beyond Claude Code (or paste SKILL.md into a Claude Project / ChatGPT custom GPT).

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
