# saved-posts-sorter: a Claude Code skill from Milli.ai

The Saved Posts Sorter. Your saved trading reels into a ranked shortlist of strategies worth testing. Parses your Instagram/TikTok export, pulls the claim and exact rule, scores testability.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment SAVED on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/saved-posts-sorter/` (every project) or `.claude/skills/saved-posts-sorter/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/saved-posts-sorter` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "Saved Posts Sorter".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Python 3.8+ (no packages). Your Instagram/TikTok data export.

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
