
Want it every weekday at 7:30? Type `/alert-inbox schedule`.

## The 6 scam red flags it checks

1. Asks you to move money or "verify" through a link
2. Guaranteed returns or a fixed daily %
3. Broker name, wrong email domain
4. A tiny stock pushed by someone you never subscribed to
5. Urgency plus secrecy
6. Asks for a seed phrase, API secret or 2FA code. **Always a scam.**
