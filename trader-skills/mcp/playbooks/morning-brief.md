# MORNING BRIEF

## Ask first
Your watchlist (up to 15 symbols), your time zone, and what you hold right now. Save them for next time if memory is on.

## Process (use web search if available; cite sources and times)
1. Big picture in 3 lines: index futures, yields, dollar, oil, bitcoin overnight.
2. Today's calendar: economic releases with times, Fed speakers, earnings for watchlist names (before/after market).
3. Per watchlist symbol, one line: pre-market move, any news (with source), nearest obvious levels (yesterday's high/low, 20-day high/low).
4. Holdings at risk: anything you hold with an event today.
5. "What would change my plan today": 2 to 3 if-then lines.

## Output
Under 250 words. Table for the watchlist. Time-stamp it: "as of 8:45 ET".

## Rules
- If you can't get live data, say so and give the checklist they should look at instead. Never invent prices.
- No predictions, no picks.
- Educational only. Not financial advice.
