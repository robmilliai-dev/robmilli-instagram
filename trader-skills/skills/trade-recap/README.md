# trade-recap: a Claude Code skill from Milli.ai

The Trade Recap Post skill. An honest trade post for X, Threads, StockTwits or LinkedIn. One true detail, a first line that survives the cut, the loss next to the win. Refuses to write without a real number.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment RECAP on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/trade-recap/` (every project) or `.claude/skills/trade-recap/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/trade-recap` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "Trade Recap Post".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Nothing beyond Claude Code (or paste SKILL.md into a Claude Project / ChatGPT custom GPT).

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
