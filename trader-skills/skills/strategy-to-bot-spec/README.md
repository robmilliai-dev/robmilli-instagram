# strategy-to-bot-spec: a Claude Code skill from Milli.ai

The Strategy-to-Bot Spec skill. Any trading idea into an exact build spec a developer or AI coder can build without guessing: every rule, data, timing, risk limits, kill switch, test plan, definition of done.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment SPEC on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/strategy-to-bot-spec/` (every project) or `.claude/skills/strategy-to-bot-spec/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/strategy-to-bot-spec` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "Strategy-to-Bot Spec".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Nothing beyond Claude Code (or paste SKILL.md into a Claude Project / ChatGPT custom GPT).

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
