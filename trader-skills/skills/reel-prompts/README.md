# reel-prompts: a Claude Code skill from Milli.ai

The AI B-Roll Prompt skill. Twelve 2-second trading hooks for AI video models, a master prompt template, shot plans for 5 trading video types and a credit estimate before you generate.

From the Milli.ai Trader Skills pack · milli-ai.com/free · comment BROLL on @robmilli.ai

## Install
1. Copy this folder to `~/.claude/skills/reel-prompts/` (every project) or `.claude/skills/reel-prompts/` (one project).
2. Open Claude Code. It finds the skill automatically.
3. Run `/reel-prompts` or just describe the task.

No Claude Code? Paste SKILL.md into a Claude Project's instructions or a custom GPT. Or connect the Milli MCP (milli-ai.com/mcp) and ask for "AI B-Roll Prompt".

## Edit first
Fill every `[bracket]` with your own numbers: your risk %, broker, watchlist. Someone else's constants are worse than none.

## Requirements
Nothing beyond Claude Code (or paste SKILL.md into a Claude Project / ChatGPT custom GPT).

## Safety
Read every file before you run it. Nothing in this pack places trades. Keep API keys in `.env`, never in code or chats.
