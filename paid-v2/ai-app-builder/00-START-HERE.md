## Which tool?

| Tool type | Examples | Best for | You'll need |
|---|---|---|---|
| Browser app agents | Replit Agent, Lovable, Bolt | Non-developers; fastest to a live link; hosting included | A browser and an account |
| Coding agents | Claude Code, Cursor, and similar | People comfortable with a terminal or code editor; more control | A computer, some setup, a hosting service |

If you've never written code, start with a browser app agent. If you have, a coding agent gives you more control and keeps the code in your own repository. Everything in chapters 02-07 applies to both.

## What it costs

| Item | Typical cost | Notes |
|---|---|---|
| AI app builder | Free tier to about $20-50/month | Most have free tiers with limited usage; heavy building uses credits faster. Check current pricing |
| Hosting | Often included in browser builders; free tiers elsewhere | Always-on or high-traffic apps cost more |
| Domain name | About $10-20/year | Optional; the builder gives you a free subdomain |
| Database and logins | Usually included or free tiers | Supabase, Firebase, Replit's database and others |
| Payments | Per transaction (Stripe: a percentage plus a small fixed fee; check current rates) | No monthly fee for the basics |

Set a spending limit or budget alert in every tool before you start. Chapter 08 covers how bills surprise people.

## Four rules the whole kit runs on

1. **Smaller than you think.** The weekend version does one job well for one kind of user. Everything else goes on the "later" list.
2. **One feature per prompt.** Ask for one change, test it, save a checkpoint, then ask for the next. Big prompts produce big messes.
3. **You own the checks.** The AI says "done" often when it isn't. You click every button, try every form and test on your phone.
4. **Secrets and money get extra care.** API keys never go in code or chat, payments are tested in test mode first, and anything handling personal data follows chapter 05.
