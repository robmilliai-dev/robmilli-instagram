**What this does:** Claude Code is an AI helper that works inside a folder on your computer. Coders use it to write software. You'll use it to run your business: read your notes, write proposals and reports, draft follow-ups, sort files, and do boring jobs on a schedule while you're away.

**What you'll have in 30 minutes:**

**What you need:** A computer and a Claude plan that includes Claude Code. No coding. You'll type about 5 simple commands, and we show you each one.

## What Claude Code does and doesn't do here

It reads and writes files in your workspace, runs commands you allow, and can use connected tools. It doesn't send emails, publish posts or pay anything unless you've connected a tool that can and allowed it. This kit is set up so it **drafts and you approve**: drafts go in `drafts/`, and the business brain tells Claude to ask before sending, publishing, deleting or paying.

It can make mistakes, misread a file or state something wrongly. That's why everything it writes is a draft, why the business brain forbids invented facts, and why chapter 06 adds version history so any change can be undone.
