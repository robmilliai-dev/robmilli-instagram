# Start here: 10 free GitHub tools you can get paid to set up

**What this does:** Lots of businesses need free, open-source software set up for them. They don't know how. You do (with AI's help). This kit gives you 10 real tools, who would pay for each one, and exactly how to start.

**What you'll have in 30 minutes:**

- ✅ One buyer group you can reach without ads
- ✅ One tool picked from the shortlist that fixes their problem
- ✅ A simple scorecard that tells you "go" or "skip"

**What you need:** A notes app, a web browser, and [Claude](https://claude.ai/) to help you think it through. No coding needed to start.

## The big idea

You're not reselling someone else's app. You're selling **your time setting it up** for a buyer who has a real problem. The free tool is just what you use to fix it.

## Step 1: Pick your buyer (5 minutes)

Write down one group of people you can reach without paying for ads. Then ask: **"What boring task are they doing badly every week?"**

Example: a local clinic. Don't start with a chatbot that touches patient data. Start with something safe, like an alert that tells them if their website goes down.

## Step 2: Pick a tool

Open [the 30-minute first win](01-first-win-and-tier-one.md). The tools are sorted into 3 levels:

| Level | What you do | Pick it when |
|---|---|---|
| 1: Set it up | Install and look after one app | You know a small group with a clear problem. **Start here.** |
| 2: Connect it | Hook the app into tools they already use | They already have data and someone in charge of it. |
| 3: Specialist | Sensitive data or heavy-duty setups | You can handle security and emergencies. |

Each tool comes with: the GitHub link, who buys it, what to sell, 3 steps to start, and the one big risk to check.

## Step 3: Check the tool is safe to use (5 minutes)

On the tool's GitHub page:

1. Click **Commits**. Is it updated in the last few months?
2. Click **Releases**. Are there recent versions?
3. Click **LICENSE**. Does it let you host and change it for a client?

Not sure about the license? Pick a different tool, or ask a lawyer. Stars on GitHub don't mean people will pay.

## Step 4: Score it

Use the scorecard to say **go** or **skip**. If the buyer can't tell you their problem, who's in charge, and what "success" looks like, skip it for now.

✅ **You're done when** you have one buyer, one tool, one "go" score, and a small first job to offer them.
