# Start here: 12 free GitHub projects you could build a paid service around

**What this does:** It gives you 12 ready-made ideas. Each one takes free software from GitHub and shows who might pay you to set it up, run it, or build on it. You get a simple 30-minute check, so you don't waste a weekend on a dud.

**What you'll have in 30 minutes:**

- ✅ One GitHub project checked: is it alive, and can you use it for paid work?
- ✅ One buyer you can ask
- ✅ A clear call: interview, build a quick test, or skip

**What you need:** A web browser and a notes app. That's it.

## Step 1: Pick a project

Pick one from the 12 in the brief chapters, or one your buyers already talk about.

## Step 2: Check it in 10 minutes

On its GitHub page:

1. **Insights → Pulse:** has anyone worked on it lately?
2. **Releases:** are there recent versions?
3. **Issues:** are lots of people stuck with no answers?
4. **LICENSE:** does it let you host it and charge for your work?

Write down the date you checked. Stars don't mean people will pay.

## Step 3: Fill in this quick filter

```text
Repo link:
Who's the buyer, and what job is painful for them:
Proof of the pain (a public issue or a chat with a buyer, with the date):
What I add that the project doesn't:
License OK? (checked / need to ask a lawyer):
Last update, last release, do the owners reply? (with dates):
A quick 30-minute test I could build:
One buyer I can ask:
My call: interview / build a test / skip. Why:
```

✅ **You're done when** the filter is filled in and you've made a call.

Can't name a buyer, or the license doesn't allow it? **Skip it.** Pick the next one.
