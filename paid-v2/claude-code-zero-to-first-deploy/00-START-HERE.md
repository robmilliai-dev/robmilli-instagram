# Start here: build and launch your first website with Claude Code

**What this does:** You tell Claude Code what you want in plain English. It builds a real website. You drag one folder onto Netlify, and it's live on the internet with a link you can share. No coding skills needed.

**What you'll have in 30 minutes:**

- ✅ Claude Code installed on your computer
- ✅ A one-page website, built by AI
- ✅ A real, live link you can send to anyone

**What you need:**

- A computer with a terminal (Mac, Windows or Linux)
- A [Claude plan](https://claude.com/pricing) that includes Claude Code
- A free [Netlify](https://app.netlify.com/drop) account

No domain to buy. No database. No coding.

## Step 1: Write a 3-line plan (5 minutes)

Before you open anything, write:

1. **Who** is the page for?
2. **What** should they find?
3. **One thing** they should do.

Example: "Neighbors looking for a free repair meetup. Show the date, place and access info. Ask them to email the organizer."

Only use real contact info you own. No fake forms or made-up reviews.

## Step 2: Install, build and launch (25 minutes)

Open [Chapter 01](01-first-live-page.md) and follow it step by step. You'll:

1. Install Claude Code (one command, copy and paste)
2. Paste in the ready-made build prompt from the [prompt cards](prompts/build-prompts.md)
3. Open your new page on your own computer to check it
4. Drag the folder onto [Netlify Drop](https://app.netlify.com/drop)

✅ **You're live when** you open your link in a private browser window and the page loads, with your real info on it.

## If something goes wrong

Go to [Chapter 03](03-when-it-goes-wrong.md). It lists the errors you're most likely to see and exactly how to fix each one.

| Quick fixes | |
|---|---|
| `claude: command not found` | Close and reopen the terminal, then try again. |
| The page looks blank on Netlify | Make sure `index.html` is in the top of the folder you dragged. |

## Good to know

- Your site is public. Remove private phone numbers, addresses and secret keys.
- Only use images you have the right to use.
- Need logins, payments or a store? Start with this simple page first. Build the big one after.
- Menus and install steps change sometimes. If a screen looks different, check the [Claude Code quickstart](https://code.claude.com/docs/en/quickstart).
